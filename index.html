我是谁

AI 产品评测方法论

Skill 评测与召回决策系统

AI 质量体系 · Skill 召回决策产品设计与落地 · 2026 — 至今
三层评测机制已运行 · 用场景相对增益选择 Skill · 一份 Trace 支持达标与横评
把多 Skill 召回“到底选谁”从算法排序问题转化为产品决策系统，用三层评测与场景相对增益建立可比较、可复用的选择依据。
  • 判断针对通用 Skill 绝对分天然占优的问题，以相对基线增益衡量场景匹配度。
  • 机制将静态过滤、单 Skill 达标和同类横评组织成三层流程，一份执行 Trace 同时支持达标判断与横评。
  • 落地将评测标准沉淀为可重复运行的流程，已支持三层评测；下一步扩大场景覆盖，并验证对线上召回选择的实际改善。

Judgement

产品判断

以下是我在真实项目中形成的三个产品判断。
  • 召回应比较增益，而不是只看谁更强同一个问题常同时命中通用和专用 Skill。只看绝对分，通用 Skill 会长期占优；我更关心它在具体场景里相对基线提升了多少。
  • 社区要提供答案之外的确定性通用 Agent 已经能搜索和生成，社区不能只重复答案。它更有价值的是来自真实经验的社会验证，帮助用户判断一个做法在自己的处境中是否可用。
  • 增长之后，继续追问增长质量Skill Finder 的 UV 周环比提升 67.7% 后，我继续拆解渠道质量、留存与召回，避免把拉新直接等同于产品成功。
